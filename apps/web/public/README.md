# Public Assets

Drop static files here. They're served at the root of the site.

## Required per client

- `og-default.png` — 1200×630 PNG used as the default Open Graph image. Generate one with branded colors and the site name.
- `favicon.ico` — standard favicon
- `apple-touch-icon.png` — 180×180 PNG for iOS home screen

The included `og-default.svg` is a placeholder. Replace it with `og-default.png` per client.
